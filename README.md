Project to make a fast food combo calculator, to find the best value combo available, within your price range, brand choice, etc. Use the calculator by opening index.html, creating a new list and putting in your filters, inputting combos that aren't already present, or editing details of existing ones. Your lists will save locally on your device, and can be imported or exported. If editing this project, mainly concern yourself with the script.js file for changing logic. the css and html are purely for design and layout.
